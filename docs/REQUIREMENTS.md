# Requirements index

This is a map, not the spec. Find the area here, then open that one file. Rows are
`| ID | requirement | STATUS |`; the rules for ids and status letters are in
`skills/requirement-first/SKILL.md`.

## How to work (part one)

| File | Holds |
|---|---|
| `requirements/p1-standing-instructions.md` | The founder's own rules, quoted. Read before any change. |
| `requirements/p1-traps.md` | Mistakes that apply everywhere. |
| `requirements/p1-open-questions.md` | What is waiting on the founder. |
| `requirements/p1-closed-decisions.md` | What was decided, and why. |
| `requirements/p1-rejected.md` | What was turned down, and why. |
