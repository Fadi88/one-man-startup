# LAUNCH: launch requirements

Requirements decided during setup that must be implemented before launch, derived from consumer customer size, target regions (AE, DE), financial data sensitivity, and free tier controls.

| ID | Requirement | Status |
|---|---|---|
| LAUNCH-1 | Self-serve account creation and email login for consumer users. | X |
| LAUNCH-2 | Privacy notice presented before account signup detailing receipt data handling and user rights under UAE PDPL and EU GDPR. | X |
| LAUNCH-3 | Machine-readable data export allowing users to download their stored receipt data and category summaries. | X |
| LAUNCH-4 | Self-serve account deletion that removes user receipt photos, amounts, vendor details, and email from active storage. | X |
| LAUNCH-5 | Cookie and tracking consent banner compliant with German TDDDG and EU GDPR before loading non-essential scripts. | X |
| LAUNCH-6 | Consumer right of withdrawal notice and waiver checkbox at checkout for digital service performance under German Civil Code (BGB § 356(5)). | X |
| LAUNCH-7 | Web subscription cancellation button (Kuendigungsbutton) under the German Fair Consumer Contracts Act (BGB § 312k). | X |
| LAUNCH-8 | Clear price display showing total subscription cost including applicable VAT and currency under German Preisangabenverordnung (PAngV). | X |
| LAUNCH-9 | Legal provider identification (Impressum) accessible on website under German Digitale-Dienste-Gesetz (§ 5 DDG). | X |
| LAUNCH-10 | Encrypted transit and storage for uploaded receipt photos and extracted financial transaction records. | X |
| LAUNCH-11 | User interface disclosure that receipt data extraction and categorization are automated using AI under EU AI Act Article 50. | X |
| LAUNCH-12 | Legal review of cross-border data transfer safeguards before sending receipt images or data to third-country AI APIs. | X |
| LAUNCH-13 | Free tier per-user monthly receipt scan cap, with numerical limit open for founder to set after prototype unit cost measurement. | X |
| LAUNCH-14 | Free tier tighter per-device guest receipt scan cap without sign-up, with numerical limit open for founder to set after prototype unit cost measurement. | X |
| LAUNCH-15 | Global daily AI spend ceiling circuit breaker that pauses free tier receipt scans when reached. | X |
