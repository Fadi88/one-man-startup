## What held on both tools

- The constitution and skills were followed from plain Markdown by both models: rounds with
  recommendations, the strict free tier as tested requirement rows, rejected ideas recorded with
  dates and reasons, the cross-border data question raised for `legal`, nothing committed.
- Both recommended strict gates, explained them, and recorded the founder's choice of standard
  with her own words.
- The sweep caught and forced fixes for what each agent broke along the way.

## What the runs exposed, and the fixes

| # | Found in | Problem | Fix |
|---|---|---|---|
| F1 to F8 | Run 1 | Setup tree order, unmeasured time costs, a dead file reference, leftover pointer files, commands before code, where rows go, interview length, a missing founder line | Fixed on 14 October; see run 1's result |
| F9 | Both | "Standard" and "light" gates were never defined, so each model invented a meaning (run 2 said standard skips the commit hook) | `skills/gates/SKILL.md` defines all three levels and what never relaxes; setup must use its table |
| F10 | Run 2 | Sources that do not exist were cited as "checked" | `skills/verified-claims/`: cite only pages opened in the session, with a quote; new `tools/link_check.py`; the legal review and setup run it on the packs; rubric M9 now requires every cited URL to exist |
| F11 | Run 2 | The interviewer used founder facts before they were given; founder answers pasted in the third person | `prompt.md` keeps the roles apart explicitly; rubric M0 checks it |
| F12 | Run 2 | A rule the template imposes (no uncapped free tier) was logged as the founder's rejection | `skills/decision-log/`: only proposals actually put to the founder are founder rejections |
| F13 | Run 2 (its own finding) | Setup's finish step did not rebuild the requirements index | Added to `skills/setup/SKILL.md` |
| F14 | Run 2 (its own finding) | `git config` without `--local` | Setup now uses `--local` |
| F15 | Run 2 (its own finding) | Dropping the running tool from `[tools] targets` deletes its own files | Setup now always includes the tool running it |

## Limits of these tests

- In both runs one agent played both interviewer and founder, so the founder's answers are not
  independent. A run with a real non-technical founder is still open (`docs/ASSUMPTIONS.md` A-7).
- Run 2 told Antigravity which files to read. Whether Antigravity, Codex, Gemini CLI or Cursor
  load `AGENTS.md` and the generated files by themselves is still open (A-2 to A-5).
- Link checks show a page exists, not that it says what the pack claims. The quote rule (F10)
  makes that checkable by a person.
